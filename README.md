# asloxp · prototipos públicos de ASLO

**Sitio de prueba:** https://xxxaga-dev.github.io/asloxp/

El repositorio público contiene exclusivamente una experiencia UX ficticia. Las decisiones, reglas de negocio y documentación del producto ASLO permanecen en un repositorio privado aparte.

## Iteración actual: experiencia inmersiva para visitantes

- Portada amplia de arena deportiva, con panel de partido destacado y controles de carrusel.
- Selección de ligas con buscador y filtro regional, detalle de liga y torneos con pestañas navegables.
- Centro de partidos con vista alternable de resultados y próximos encuentros.
- Transiciones visuales de las secciones públicas; admite preferencia de movimiento reducido.
- Música ambiental **original sintetizada con Web Audio**, voluntaria y apagada de forma predeterminada. Se inicia únicamente por acción directa del visitante; se mantiene al navegar entre páginas públicas sin salir de ellas.
- Idiomas de prueba: español, inglés y alemán; tema claro/oscuro/sistema para esta propuesta visual.
- Acceso, registro, menú de usuario y modos: permanecen como prototipos anteriores, fuera de esta transformación visual.

**Importante:** no son resultados reales ni datos en vivo, no hay streaming de partidos ni permisos/autenticación reales. No introducir datos personales o contraseñas reales. Sin música de terceros, imágenes de clubes reales ni recursos del videojuego FIFA/EA Sports.
