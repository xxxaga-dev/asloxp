# asloxp · prototipos públicos de ASLO

Sitio de prueba incremental para el diseño de UX de ASLO. El proyecto real y sus decisiones permanecen en el repositorio privado.

**Ver en GitHub Pages:** https://xxxaga-dev.github.io/asloxp/

**Recorrido actual:** visitante → acceso / registro simulados → elegir un modo → abrir menú de usuario → perfil, seguridad, apariencia e idioma → cerrar sesión.

Idiomas de interfaz de prueba: español, inglés y alemán. Temas: claro, oscuro y según dispositivo.

**Advertencia de seguridad:** no hay autenticación, cambio de contraseña, verificación de dos pasos ni base de datos. No introducir nombres, correos ni contraseñas reales. Solo se guarda el idioma/tema en las preferencias del navegador y la cuenta ficticia en la sesión de la pestaña.
