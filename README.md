# asloxp · prototipos públicos de ASLO

Prototipo UX estático para revisar una parte de ASLO por iteración. Proyecto y decisiones privadas se mantienen fuera de este repositorio.

**Sitio:** https://xxxaga-dev.github.io/asloxp/

**Iteración actual:** visitante anónimo → inicio de sesión / registro simulados → cambio de modo según cuenta de ejemplo. [Inicia aquí](index.html).

**IMPORTANTE:** no hay autenticación real ni base de datos. No introducir datos sensibles, correos reales ni contraseñas reales. Los modos simulados no conceden autorizaciones reales.
